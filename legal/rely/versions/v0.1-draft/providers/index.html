本清单是《Rely 隐私政策》的配套告知文件。受托服务商只能在约定范围内处理；服务商独立处理个人信息的，应另行识别其角色并依法完成所需告知和单独同意。

用户自行配置模型连接的功能如开放，也须符合境内处理及禁止训练要求；调用时会向所选服务发送必要任务资料，并使用所填 API 密钥完成身份验证。实际接收方及其处理规则须在使用前明确。

二、留存与变更

  • 公司自身的账号、项目、日志留存按隐私政策执行；接收方的留存期限及备份轮换应具体填列，不能以“按第三方政策”为由隐藏必要信息。
  • 删除请求涉及服务商保存的数据时，公司按适用法律和委托约定同步落实删除及必要限制。
  • 新增接收方、改变处理用途或数据范围时，在处理发生前更新清单并依法完成告知、同意和其他必要程序。
  • 本版未纳入微信登录、支付、广告追踪或境外模型。实际开通这些功能前，应核对并更新，不能把本清单作为概括授权。
